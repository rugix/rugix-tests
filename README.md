# Rugix Tests

> [!IMPORTANT]
> **Retired:** This repository is no longer maintained. Each Rugix project now
> has its own system tests.

This repository used to hold a shared system test suite that
[Rugix Ctrl](https://github.com/rugix/rugix) and
[Rugix Bakery](https://github.com/rugix/rugix-bakery) included as a submodule.
The tests now live with the projects they test:

- [Rugix Ctrl and Rugix Bundler](https://github.com/rugix/rugix/tree/main/tests)
- [Rugix Bakery](https://github.com/rugix/rugix-bakery/tree/main/tests)
- [Rugix Admin](https://github.com/rugix/rugix-admin/tree/main/tests)

[Rugix Testkit](https://github.com/rugix/rugix-testkit) provides the shared
test infrastructure, including a pytest plugin and a base layer for test
systems.
